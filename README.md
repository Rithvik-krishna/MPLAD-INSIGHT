# MPLAD-INSIGHT AI

MPLAD Insight AI is an AI-powered governance and public fund oversight platform engineered for monitoring Member of Parliament Local Area Development Scheme (MPLADS) funds, tracking project status, analyzing fund utilization anomalies, and managing compliance.

## 🚀 Features

- **Overview Dashboard**: High-level financial KPIs, fund utilization trends, and high-risk case summaries.
- **Analytics Engine**: Deep-dive analytics on expenditure anomalies, district performance benchmarks, and spending velocity.
- **Geographic Map**: Interactive spatial visualization of MPLADS projects across constituencies.
- **Flagged Cases & AI Audits**: Automated flagging of delayed, lapsed, or suspicious transactions with risk scoring.
- **Case Details**: In-depth audit breakdowns, timeline tracking, and action items for flagged projects.
- **Data Explorer**: Comprehensive tabular data viewer with multi-faceted filtering and search.

## 🎨 Design System

The platform is designed following the **MPLAD Insight Design System** (Inter typography, Slate/Indigo palette, fixed-fluid responsive layout, standard 8px spacing scale).
